Preparar a IDE Arduino

Faça uma vez em cada computador. Depois é só baixar o código gerado pela plataforma, preencher o Wi-Fi e gravar.

1. Suporte às placas ESP32 / ESP8266

  1. Instale a IDE Arduino 2, se ainda não tiver.
  2. Arquivo › Preferências › URLs adicionais para Gerenciadores de Placas: cole as duas linhas abaixo (uma por linha) e clique em OK. 
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
https://arduino.esp8266.com/stable/package_esp8266com_index.json
  3. Ferramentas › Placa › Gerenciador de Placas: instale esp32 (Espressif Systems) e/ou esp8266 (ESP8266 Community).
  4. Escolha a placa em Ferramentas › Placa: ESP32 Dev Module para ESP32 comum, ou NodeMCU 1.0 (ESP-12E Module) para ESP8266 NodeMCU.

2. Bibliotecas

São só duas. Wi-Fi, HTTP e TLS já vêm com o suporte à placa.

BibliotecaComo instalar
SensorSync
versão 1.2 (com TLS)		 Baixar SensorSync.zip
Na IDE: Sketch › Incluir Biblioteca › Adicionar biblioteca .ZIP… e escolha o arquivo (não descompacte). Para atualizar, apague antes a pasta Documentos\Arduino\libraries\SensorSync.
PubSubClient
Nick O'Leary		 Ferramentas › Gerenciar Bibliotecas, procure "PubSubClient" e instale a de Nick O'Leary. Necessária mesmo se você usar só HTTP.

Confira em Arquivo › Exemplos › SensorSync: devem aparecer HTTP_Basico, MQTT_Basico, TLS_Basico e WiFi_Externo. Se houver uma pasta antiga sensor_sync em libraries, apague.

3. A placa não aparece em Ferramentas › Porta?

  • Use um cabo USB de dados (muitos cabos só carregam).
  • Instale o driver do conversor USB da placa: CP210x (Silicon Labs) ou CH340 (WCH). O nome do chip costuma estar impresso perto do conector USB.
  • Se a gravação parar em "Connecting....", segure o botão BOOT da placa até começar a gravar.

4. Mensagens no Monitor Serial (115200)

MensagemO que fazer
Fica em Conectando ao Wi-FiConfira WIFI_SSID e WIFI_PASSWORD. O ESP só conecta em redes de 2,4 GHz.
Broker inacessivel / Servidor inacessivelServidor desligado, endereço errado no código ou firewall bloqueando as portas 8443/8883. Avise o administrador.
Token recusado (401)O token foi trocado ou digitado errado. Gere um novo na aba Dispositivos do projeto e baixe o código de novo.
Servidor pede HTTPSO código é de antes do TLS. Baixe o código de novo na aba Código.
TLS ... (certificado, nome)O endereço do servidor no código não bate com o certificado, ou o servidor gerou uma CA nova. Baixe o código de novo; se continuar, avise o administrador.
Nada apareceConfira a velocidade 115200 no Monitor Serial e se a gravação terminou ("Done uploading"); aperte o botão EN/RST da placa.
