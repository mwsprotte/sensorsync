Histórico

Nenhuma variável marcada como gráfico neste projeto.

Aguardando os primeiros envios deste dispositivo.

Cada dispositivo usa o próprio token e só consegue gravar neste projeto. O token aparece uma única vez; se perder, gere outro (o anterior para de funcionar).

Opções

O dispositivo é o selecionado no topo da página.

Como gravar

  1. Na IDE Arduino, instale a biblioteca SensorSync em Ferramentas › Gerenciar Bibliotecas. A PubSubClient vem junto.
  2. Baixe o .ino e preencha WIFI_SSID e WIFI_PASSWORD. O ESP só conecta em redes de 2,4 GHz.
  3. Substitua os random() pelas leituras dos sensores.
  4. Grave a placa e acompanhe pelo Monitor Serial (115200).
