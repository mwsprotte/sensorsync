Certificado do servidor

Este servidor está sem TLS (HTTP puro), então não há certificado para instalar.

A conexão com a plataforma já é criptografada. O aviso "Não seguro" aparece só porque o certificado foi criado pelo próprio servidor do laboratório, e o computador ainda não o conhece. Instale uma vez em cada computador e o aviso some.

Windows (Edge e Chrome): um comando

  1. Abra o PowerShell (menu Iniciar › digite "PowerShell"; não precisa ser administrador).
  2. Copie o comando abaixo (é uma linha só), cole no PowerShell e tecle Enter.
  3. No aviso de segurança do Windows, confira se a impressão digital (Thumbprint) é a SHA-1 mostrada no fim desta página e clique em Sim.
  4. Feche todas as janelas do navegador e abra de novo.

        Para o administrador
        
    
            
  • O certificado é criado no primeiro boot por sensorsync-tls.service, em
                /etc/sensorsync/tls. Impressão digital no servidor:
                openssl x509 -in /etc/sensorsync/tls/ca.crt -noout -fingerprint -sha1.
    • 
            
  • Se o IP do servidor mudar, só o certificado do servidor é refeito; esta CA continua a mesma e não é preciso
                reinstalar nada nos computadores nem regravar as placas.
    • 
            
  • Uma CA nova (troca de SENSORSYNC_TLS_KEY ou pasta apagada) exige reinstalar aqui e gerar de novo o
                código das placas. Para remover a antiga no Windows: certmgr.msc › Autoridades de Certificação Raiz
                Confiáveis › Certificados › "SensorSync CA ...".
    •
